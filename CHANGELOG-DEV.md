# LFC Foundry organization page developer changelog

What changed, newest first, for developers, in three depths: Quick, Details and Deep. Users read CHANGELOG.md.

## 2026-10-30 · PR 12 (picture banner and app cards)

### Quick
The profile README shows a picture banner and four app cards instead of Markdown tables.

### Details
GitHub renders the profile README as plain Markdown with no CSS, so the design is delivered as SVG pictures (`profile/images/*.svg`, ten files) with light and dark sources chosen by `<picture>`. Each image has alt text, so the page still reads if images are blocked. Light mode uses navy cards with white text and a light-blue accent, because pale cards looked washed out.

### Deep
The SVGs are generated by a small script from the same palette as the app landing pages. The rendered result was checked in light and dark at phone width with Chromium. A separate Pages site was not created, by the owner's choice; the organization page stays the profile README.

## 2026-10-30 · PR 11 and PR 10

### Quick
Lists replace wide tables; play links point at /play/.

### Details
Tables overflowed on phones, so lists are used. Each app's front page is now its landing page and the game is at `/play/`, so the links changed. Pineapple Defense and Story Editor were added with their file sizes (2.54 MB and 0.30 MB; Apple Press 0.74 MB, Fancy 0.50 MB).

## 2026-10-29 · PR 8, PR 9 and PR 7

### Quick
New top in the landing look; plain promises about installing and skills; module list updated to 49.

### Details
Root README and profile README share one top section. The promise lines (no install, no administrator rights, no special knowledge; modules are for developers) were added to both. The module list follows `modules.json` in JS-modules.
